# Historial de Conversaciones y Detalles de Conversaciones

A continuación se describen los métodos para acceder al historial de conversaciones y a los detalles de una conversación específica. Se recomienda implementar estas llamadas mediante `fetch` directamente en el front-end.

## 1. Historial de Conversaciones Anteriores

### 1.1 Método

| | |
|---|---|
| **SDK** | `olosRecordingRetrieve.getAgentConversation(agentId, conversationDate, maxLimit, callbackSuccess, callbackError)` |
| **Endpoint** | `GET WebApiRecordingRetrieve/RecordTextComm/Agent?agentId={agentId}&conversationDate={data}&maxLimit={limite}` |

#### Parámetros de Query

| Parámetro | Ejemplo | Descripción |
|---|---|---|
| `agentId` | `0` | ID del agente |
| `conversationDate` | `08%2F05%2F2026` | Fecha de las conversaciones (formato `DD/MM/YYYY`, URL-encoded) |
| `maxLimit` | `100` | Número máximo de registros retornados |

### 1.2 Retorno

Retorna todas las interacciones tabuladas del agente. Para un uso correcto:

- **Filtrar** por el campo `channelId = "whatsapp"`
- **Eliminar duplicados** por `conversationId` (cada tabulación genera un nuevo registro)

## 2. Detalle de una Conversación (Historial de Mensajes)

> **Paginación:** La API no tiene paginación nativa. Se recomienda implementar la paginación en el front-end.

### 2.1 Método

| | |
|---|---|
| **SDK** | `olosRecordingRetrieve.getConversation(conversatioId, conversationDate, maxLimit, callbackSuccess, callbackError)` |
| **Endpoint** | `GET WebApiRecordingRetrieve/RecordTextComm/Conversation?conversatioId={conversationId}&conversationDate={data}&maxLimit={limite}` |

#### Parámetros de Query

| Parámetro | Ejemplo | Descripción |
|---|---|---|
| `conversatioId` | `xxx` | ID de la conversación |
| `conversationDate` | `08/05/2026` | Fecha de la conversación (formato `DD/MM/YYYY`) |
| `maxLimit` | `100` | Número máximo de registros retornados |

### 2.2 Retorno

Retorna el historial completo de mensajes intercambiados en una conversación. El campo `direction` indica la dirección del mensaje:
